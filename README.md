# VCR Student Learning Workspace

Student-only interface: there is **no Instructor / Create Assignment tab or link**. Students open scenario-specific links, respond to Commit, Complicate, and Calibrate, save drafts, export to Canvas, and revise after feedback.

## Publish
1. Create a public GitHub repository named `VCR-Student-Workspace`.
2. Upload the files in this folder to the repository root.
3. Settings → Pages → Deploy from a branch → main → /(root).
4. Your student site will be `https://drbexjones.github.io/VCR-Student-Workspace/` if you use that repository name.
5. In the separate Instructor Creator, enter this exact student site URL and generate student assignment links.

Drafts are saved only in the student's browser when requested; downloaded backups are essential. Exports are submitted through Canvas. No server collects student work. Do not use real identifiable patient information.

Visible Clinical Reasoning framework developed by Rebecca L. Jones, EdD, CCC-SLP, Oklahoma Baptist University.
