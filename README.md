# VCR Learning Workspace

A free, static, student-facing companion to VCR Assignment Studio. Created for the Visible Clinical Reasoning (VCR) instructional design framework developed by **Rebecca L. Jones, EdD, CCC-SLP**, Oklahoma Baptist University.

## Publish on GitHub Pages

1. Create a **new public repository** (suggested name: `VCR-Learning-Workspace`). Keep your existing `VCR` repository unchanged.
2. Upload `index.html`, `styles.css`, and `script.js` to the **root** of the new repository (and optionally this README and LICENSE).
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Once published, visit `https://YOUR-USERNAME.github.io/VCR-Learning-Workspace/`.
5. In the **Instructor** tab, paste a verified clinical case, set the objective and permitted resources, and generate a student link. Test the link in a private browser window.
6. Students use the link to complete CCC, save drafts locally, download an editable JSON backup, and export HTML or TXT for Canvas. For revision, students select **Revision after instructor feedback** and type revised responses alongside their preserved initial responses.

## Privacy and important limitations

- Entirely static HTML/CSS/JavaScript; **no backend, accounts, API key, or fees**. GitHub Pages hosts public source files.
- Assignment links embed the clinical scenario and instructor instructions **in the URL itself**. **Do not include real patient information, protected health information, or confidential content**. Long links may not work everywhere; instructors can distribute an assignment `.json` file instead.
- The site does **not transmit student responses to an instructor**. Local drafts use browser `localStorage`, on the current device/browser only; students should regularly download an editable `.json` backup, especially before switching devices or clearing browser data.
- Student names and answers are included in exported files; handle these under institutional privacy and FERPA policies. Do not share student backup links/files publicly. No student responses are added to assignment URLs.
- The exported `.html` file is a **standalone readable document**, not a web submission. Students may open it in a browser and print/save as PDF if Canvas does not accept HTML uploads. The `.json` backup is for restoring/editing work, not grading.
- The faculty feedback fields are for students to **copy feedback from Canvas**, not for faculty to grade within this website. Faculty determine scores and remediation in the LMS.
- Faculty must verify AI-generated clinical content, the applicability of course policies, and accessibility requirements before assigning.

## VCR scoring protocol

Each component receives **Complete (2)**, **Revise (1)**, or **Incomplete (0)**. Initial scores below **6/6** require revision of all non-Complete components. The instructor rescores the revised work: **5–6 = 100%**, **4 = 80%**, and **0–3 = remediation (0% if not successfully completed)**, subject to instructor policy. This scores written learning activity, **not independent clinical competency**.
